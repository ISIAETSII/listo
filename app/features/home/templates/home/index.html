Listo

Un gestor de tareas pequeño, hecho con Flask y organizado por features. Es el proyecto base de la asignatura: sobre él se hacen las prácticas de gestión del código fuente, integración continua, contenedores, JavaScript y Flask.

¿Cómo está organizado?

Features

Cada funcionalidad vive en su carpeta dentro de app/features/: modelos, formularios, servicios, rutas, plantillas y tests, todo junto.

Blueprints

Las rutas de cada feature se agrupan en un blueprint que se registra en create_app(), dentro de app/__init__.py.

MariaDB + SQLAlchemy

Los modelos describen las tablas y SQLAlchemy traduce los objetos Python a SQL. Con Docker, la base de datos se levanta con un solo comando.

Estructura del proyecto

app/
├── __init__.py       ← create_app(): fábrica de la aplicación
├── config.py         ← configuración (lee el fichero .env)
├── extensions.py     ← db, login_manager, csrf
├── commands.py       ← flask init-db / seed-db / reset-db
├── templates/        ← base.html y plantillas comunes
├── static/           ← CSS y JavaScript
└── features/
    ├── home/         ← página de inicio
    ├── auth/         ← registro, login y logout
    └── tasks/        ← gestor de tareas (HTML + API JSON)
        ├── __init__.py   ← define el blueprint
        ├── models.py     ← tabla tasks
        ├── forms.py      ← formulario (WTForms)
        ├── services.py   ← lógica de negocio
        ├── routes.py     ← vistas HTML
        ├── api.py        ← endpoints JSON
        ├── seeders.py    ← datos de ejemplo
        ├── templates/    ← plantillas de la feature
        └── tests/        ← tests de la feature

¿Por dónde empiezo?

  1. Crea una cuenta (o entra con demo@listo.app / demo1234) y añade tareas.
  2. Abre app/features/tasks/ y sigue el camino de una petición: ruta → servicio → modelo → plantilla.
  3. Marca una tarea como completada: lo hace static/js/tasks.js llamando a la API JSON sin recargar la página.
  4. Ejecuta pytest y lee los tests que hay en cada feature.
  5. Crea tu propia feature copiando la estructura de tasks.
